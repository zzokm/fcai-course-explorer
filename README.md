# FCAI Courses

Course information and exploration platform for FCAI (Faculty of Computers and Artificial Intelligence).

## Tech Stack
- **Framework**: [Next.js](https://nextjs.org/) 16.3.4 (App Router, Turbopack)
- **Language**: TypeScript
- **Runtime**: React 19

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

## Project Structure
- `src/app/`: Next.js App Router root layout and page
- `data/`: Course data specifications, bylaws, and translation files
- `.agents/skills/`: Integrated agent skills (`impeccable`, `taste`, `frontend-design`, `web-design-guidelines`, `high-end-visual-design`, `design-taste-frontend`)
