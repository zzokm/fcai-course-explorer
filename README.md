# FCAI Courses

Course information and exploration platform for FCAI (Faculty of Computers and Artificial Intelligence).

## Tech Stack
- **Framework**: [Next.js](https://nextjs.org/) 16.3.4 (App Router, Turbopack)
- **Language**: TypeScript
- **Runtime**: React 19

## Getting Started

Run the development server:

```bash
npm run dev
```

**Live URL**: https://majors.yehia.dev
